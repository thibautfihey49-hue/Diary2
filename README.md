# Diary2 - HUNTR/X Journal Adulte 18+ (KPop Demon Hunters fan-made)

Journal intime adulte avec notes vocales, images, et coffre privé DATA SMS chiffré port 8090.

## ⚠️ Adulte 18+ uniquement - Double consentement
- Ce projet utilise SEND_SMS/RECEIVE_SMS sur port 8090 binaire, chiffré AES-GCM via Android Keystore
- Les deux utilisateurs doivent être adultes, avoir l'app, et consentir (échange de clés en QR)
- Métadonnées visibles opérateur, contenu chiffré
- Fan-made KPop Demon Hunters, non officiel

./gradlew assembleDebug
